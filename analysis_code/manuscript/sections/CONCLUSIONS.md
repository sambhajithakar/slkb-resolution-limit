A combinatorial screen resource has a **resolution limit**: the number of mutually independent
contexts it contains fixes the smallest p-value an exact sign-symmetry test on it can ever attain,
and at α = 0.05 that test can reject only from six independent contexts upward, five one-sided.
The limit is computed from deposited metadata alone, before a system exists, and we release the
calculator that computes it.

Measured against that limit, the public SL resource supports the label construct a retrieval
benchmark needs, but far less inference than benchmarks built on it usually claim. The eligible
design holds five independent contexts and the full deposit three, because the added screens share
cell models and studies with those already deposited — so here enlarging the resource lowered its
resolution, and a resource gains resolution only through contexts disjoint from everything already
in it. At five units the protocol's
confirmatory rule has a size and a power of exactly zero; the rules that can reject carry worst-case
measured type I errors of 0.112 and 0.136; and a symmetry diagnostic intended to restore control
raises the rate to 0.106–0.174 once measured conditional on passing, which is the only circumstance
in which a claim is made.

We therefore report the design, the audit, the feasibility and validity analysis and the pilot, and
no confirmatory comparison: it has not been run, and on this evidence should not be run at this
resolution. The contribution is a benchmark whose limits are established before its results exist,
and a criterion that lets the next benchmark establish its own.
