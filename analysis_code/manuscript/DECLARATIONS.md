**Use of AI.** An AI assistant (Anthropic Claude) was used throughout: to draft and revise this
text, to write the analysis code and its tests, to run the audit, the simulation and the authorised
pilot, and to assemble the literature search. Every numerical result reported here was produced by

author, makes no authorship claim and takes no responsibility for the work; the author(s) take full
responsibility for all content, including the parts drafted with assistance. The full disclosure
statement accompanies the submission.

**Data availability.** All primary data are public and none is redistributed here. Labels: the
Synthetic Lethality Knowledge Base [[cite:slkb]], used through the resource's own deposited SQL
dump with its publisher-stated MD5 verified. Gene popularity: NCBI Gene `gene2pubmed` and
`Homo_sapiens.gene_info`, public domain, with the download date recorded because NCBI rebuilds
these files daily and publishes no checksum. Retrieval corpus: the PubMed annual baseline, every
file verified against NCBI's published MD5 on download, with the SHA-256 of each file and the
content hash of the resulting snapshot recorded in the corpus manifest released with this paper.
Derived files released with the paper: the eligible-screen table, the per-screen and per-cell-model
aggregates, the variance components, the simulation grid and the corpus manifest. Nothing
DepMap-derived enters the primary analysis and no DepMap licence is relied upon.

author(s) at submission and at acceptance respectively; **neither exists at the time of writing and
neither is cited here**.
